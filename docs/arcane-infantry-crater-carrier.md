# 비전 보병과 분화구 운반수
두 소환 마법의 DB 계약은 ArcaneCastersDatabase V045다. 기존 single-magic-card dev 모델을 따른다.
DEFAULT 접근 정책이며 조합식은 추가하지 않는다.

| 항목 | 비전 보병 | 분화구 운반수 |
| --- | --- | --- |
| 마법/몸체 키 | arcane_infantry | crater_carrier |
| 비용 / 수량 | 20 / 1 | 45 / 1 |
| HP / 피해 | 360 / 70 | 440 / 150 |
| 공격 간격 | 1.0초 | 2.6초 |
| 공격 사거리 | 0.5 | 7.0 |
| 이동 속도 | 1.4 | 0.65 |
| 크기 / 원소 | Small / None | Medium / Fire + Rock |

분화구 운반수는 1.2초 설치 후 첫 포탄을 발사하고, 같은 자리에서 공격 간격에 맞춰 계속 쏜다.
대상을 잃거나 범위를 벗어나거나 이동 지시를 받으면 0.9초 회수한 뒤 공통 이동 AI로 돌아간다.
기절 중 이동 지시로 공성 상태를 건너뛸 수 없다. 회수 중 새 이동 지시도 타이머를 다시 시작하지 않는다.
서버 상태 Deploying/Deployed/Recovering은 준비/설치 완료/회수 자세를 전달한다.
Attack은 발사 프레임에서 유지하고 다음 tick에 지속 상태를 복구한다.

포탄은 발사자의 위치에서 높이 0.8로 출발하고, 수평 속도 6·고정 포물선 높이 2.5를 사용한다.
착탄 위치는 발사 시 지상 좌표로 복사한다. 착탄 반경 1.4 안의 살아 있는 적 지상 개체만 한 번 피해를 받는다.
발사 시 원소·진영·피해 출처를 보존하며 발사자 사망은 비행 중 포탄을 지우지 않는다.
CraterExplosion은 0.6초 표시 전용 몸체다. 피해 컴포넌트를 붙이지 않는다.

배포 순서는 DB V045 → game/client다. 마이그레이션은 별도 database 저장소에서 관리하며
버전 bump나 운영 DB 적용은 이 기능 PR에서 수행하지 않는다.
